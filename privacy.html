Privacy Policy

Shop Keyword Research. Last updated October 5, 2026.

Shop Keyword Research ("the app") is a personal tool that Anshul Jha runs on a personal computer to research search demand for products in a small online shop they own. This policy explains what Google user data the app accesses and how it is handled.

Data the app accesses

With the permission granted on Google's consent screen (the Google Ads API scope, https://www.googleapis.com/auth/adwords), the app accesses:

  • OAuth access and refresh tokens for the signed-in Google account.
  • The Google Ads customer (account) ID used to make Keyword Planner requests.
  • Keyword planning results: keyword ideas, average and monthly search volumes, competition levels and suggested bid ranges.

The app does not access campaign, ad, billing or payment data, contacts, email, or any other Google account data.

How the data is used

Keyword planning results are used only to estimate demand and seasonality for product ideas in the owner's shop. Tokens are used only to make those requests on the owner's behalf. The app never creates, changes or deletes anything in a Google Ads account.

Storage and security

  • Everything is stored locally on the owner's computer. There is no server, website backend or cloud database.
  • OAuth tokens are kept in a file readable only by the owner's user account.
  • Keyword results are kept in a local database used for research.

Sharing

Google user data is not sold, rented, shared or transferred to anyone, is not used for advertising, and is not used to train AI or machine-learning models.

Retention and deletion

Data is kept only as long as it is useful for research. Deleting the app's local files removes all stored data. Access can be revoked at any time at myaccount.google.com/permissions, after which the stored tokens stop working.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
